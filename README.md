# 🚗 BA-NG-JEK - Ojek Online Batam

Aplikasi ojek online modern untuk Kota Batam dengan fitur real-time tracking, rating system, dan integrasi WhatsApp.

## 📋 Fitur Utama

- ✅ User Authentication (Pengguna & Driver)
- ✅ Real-time Order Tracking
- ✅ WhatsApp Integration
- ✅ Rating & Review System
- ✅ Payment Integration
- ✅ Admin Dashboard

## 🚀 Instalasi & Setup

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
npm start
```

### Frontend Setup

```bash
cd frontend
# Buka index.html di browser atau gunakan live server
```
