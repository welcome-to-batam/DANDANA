# ALFA-Online-Shopping

ALFA-Online-Shopping adalah aplikasi web untuk belanja online yang memudahkan pengguna dalam mencari, memilih, dan membeli produk secara daring dengan pengalaman yang cepat dan aman.

## Fitur

- Pencarian produk dengan filter kategori dan harga
- Keranjang belanja yang mudah digunakan
- Sistem pembayaran yang aman dan terintegrasi
- Halaman profil pengguna untuk melihat riwayat pembelian
- Responsif dan dapat digunakan di berbagai perangkat

## Instalasi

Ikuti langkah berikut untuk menjalankan proyek ini secara lokal:

```bash
git clone https://github.com/welcome-to-batam/ALFA-Online-Shopping.git
cd ALFA-Online-Shopping
npm install
npm start
